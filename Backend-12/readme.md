# Authorization → Authentication → Verification → Validation

## One‑line definitions

* **Authentication**: Confirms *who* a user is by checking credentials.
* **Authorization**: Determines *what* an authenticated user is allowed to do.
* **Verification**: Checks whether provided information or actions match expected rules or data.
* **Validation**: Ensures data or input is correct, meaningful, and acceptable before processing.

## Comparison Table

| Term           | Purpose              | Happens When         | Example                      |
| -------------- | -------------------- | -------------------- | ---------------------------- |
| Authentication | Identify the user    | At login             | Entering username & password |
| Authorization  | Grant or deny access | After authentication | Admin accessing dashboard    |
| Verification   | Confirm correctness  | During checks        | OTP or email verification    |
| Validation     | Ensure data quality  | Before processing    | Form input validation        |
